# Portfolio personnel

Projet de portfolio de Jonathan Maquenhem, développeur Full Stack avec un intérêt pour le DevOps, l’intégration et les besoins métier.

Le projet est actuellement en phase de cadrage. Ce dépôt conserve les contenus préparatoires et le contexte des décisions ; aucune application n’est encore développée.

## Documentation

- [Contexte du projet](project-context.md) : objectifs, pistes graphiques et techniques, principes de conception.
- [Fiches de parcours](docs/parcours/) : expériences, projets et contributions personnelles.
- [Suivi des échanges](docs/suivi/README.md) : investigations, décisions, points ouverts et vérifications, regroupés par jour.

Les pistes décrites ne constituent pas toutes des choix définitifs. Les fiches de parcours restent des documents de travail à condenser pour le site et comportent des points de publication à vérifier.

## Reprendre le projet

```sh
git clone https://github.com/FireFox-d3vFR/portfolio.git
cd portfolio
```

Lire le contexte, puis le suivi le plus récent avant de poursuivre. Aucun outil de build ni dépendance applicative n’est nécessaire à ce stade.
