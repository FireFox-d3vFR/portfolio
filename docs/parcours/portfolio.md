# Portfolio personnel

Catégorie : projet personnel.
Période : depuis octobre 2026.
Statut : en cours de réalisation ; déploiement public non encore confirmé.

## Objectif et démarche

Présenter le parcours de Jonathan, ses contributions et ses réalisations dans un espace personnel complémentaire de GitHub. Le travail a commencé par le contexte, les fiches de parcours et un cadrage V1, puis par une maquette Lovable en React utilisée comme référence visuelle.

La réalisation adapte cette base sous Astro, avec des itérations sur le texte, les composants et les interactions à partir des retours de Jonathan. L’identité actuelle associe une palette automnale, Fraunces, Manrope et JetBrains Mono, un univers géométrique et un renard dont les variantes sont documentées sur la page identité.

## Réalisation

- Site statique en composants Astro, stylé avec Tailwind CSS et des variables CSS.
- Interactions TypeScript : modales natives, galeries, vues grille/liste et parcours Git filtrable.
- Quatre thèmes saisonniers avec sélection automatique selon la date ou choix manuel et mode sombre indépendant.
- Contenus hiérarchisés entre aperçu et détails ; distinction entre expérience professionnelle et réalisation applicative pour Orange.
- Responsive, navigation clavier, préférences de mouvement et suivi éditorial documenté.

## Technologies et publication

Astro, TypeScript, Tailwind CSS. Vercel est la cible d’hébergement validée, pas une mise en ligne déjà réalisée. Aucun backend, formulaire serveur, base de données ou authentification ajouté.

Dépôt : https://github.com/FireFox-d3vFR/portfolio
