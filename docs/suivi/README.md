# Suivi du projet

Ce dossier conserve les investigations, remarques, décisions et vérifications effectuées pendant les échanges sur le portfolio.

## Organisation

- Un fichier par jour, nommé `AAAA-MM-JJ.md`, selon la date en Europe/Paris.
- Les échanges supplémentaires du même jour complètent le fichier existant.
- Reprendre les demandes d’origine quand elles sont disponibles, sans reconstruire les demandes manquantes.
- Distinguer les faits observés, les recommandations, les décisions confirmées et les pistes ouvertes.
- Consigner les changements réellement effectués et les vérifications réellement exécutées, avec leur résultat.
- Ne pas présenter une suggestion comme un choix validé, ni une vérification prévue comme un test effectué.
- Conserver un historique concis et utile ; éviter les transcriptions intégrales des sorties d’outils et les répétitions.

Le document `project-context.md` reste la base de réflexion du projet. Ce suivi conserve le contexte des échanges et des choix sans rendre les pistes proposées définitives.
